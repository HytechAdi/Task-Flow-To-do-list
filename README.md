
# TaskFlow | To-Do List

**Plan your day. Get things done.**

TaskFlow is a simple and modern To-Do List web application that helps users organize daily tasks, track their progress, and stay productive. It has a clean interface that makes managing everyday tasks easy.

## ✨ Features

* **Add Tasks:** Quickly add new tasks to your daily list.
* **Task Management:** Organize your tasks in one place.
* **Mark as Completed:** Mark tasks as completed when you finish them.
* **Task Statistics:** View total, pending, and completed task counts.
* **Delete Tasks:** Remove tasks you no longer need.
* **Clear Completed:** Clear completed tasks from the list.
* **Current Date:** Display the current date.
* **Responsive Design:** Designed to work across different screen sizes.

## 🚀 Getting Started

Follow these steps to run TaskFlow on your computer.

### Step 1: Download the Project

Download or clone the project repository to your computer.

### Step 2: Open the Project Folder

Make sure the following files are present:

* `index.html`
* `style.css`
* `script.js`

### Step 3: Run the Application

Open `index.html` in your web browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.

## 📖 How to Use

1. Open TaskFlow in your browser.
2. Enter a task in the input field.
3. Click **Add Task** to add it to your list.
4. Mark a task as completed when you finish it.
5. Delete individual tasks when needed.
6. Use the task statistics to track your progress.
7. Click **Clear completed** to remove completed tasks.

## 🎯 Project Objective

The main objective of TaskFlow is to provide a simple and user-friendly way to manage daily activities. It helps users organize their work, monitor task progress, and improve productivity.
